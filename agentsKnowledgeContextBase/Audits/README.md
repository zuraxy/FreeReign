# Route DJ audits

Audits are formal, evidence-based reviews of the current implementation. They record risks and follow-up work without presenting planned fixes as completed.

## Naming convention

Use descriptive PascalCase names, optionally prefixed by a date when recurring, for example `InitialFrontendAudit.md` or `2026-08-AccessibilityAudit.md`.

## Suggested categories

- Architecture
- UI consistency
- Accessibility
- Performance
- State management
- Test coverage
- Maintainability
- Backend-readiness
